|---|---|---|---|
| 北 | 黄 | Cult Uprising 邪教暴动 | 6 / 5 |
| 东 | 蓝 | Drunk 醉酒 | 4 / 3 |
| 东 | 蓝 | Disarmed 缴械 | 2 / 2 |
| 西 | 红 | Drunk 醉酒 | 5 / 5 |
| 西 | 红 | Mermaid 美人鱼 | 2 / 2 |
| 西 | 红 | Telescope 望远镜 | 2 / 2 |
| 西 | 红 | Armed 武装 | 2 / 0 |

- 每人开局 3 把枪。
- 停职牌数量：5-6人1张、7-8人2张、9-11人3张。
- 邪教仪式牌 5 张：3×皈依邪教、1×邪教军火库、1×邪教舱室搜查，洗混背面放置。
- 长航程地图行动格：4×舱室搜查、2×鞭刑、1×割舌、3×献祭海妖；快航程：3×舱室搜查、2×献祭海妖。
- 快航程无补给线；长航程有（穿过时全员补枪至3）。
- "I am not a..."卡 + 3 张小鞭刑卡（7-11人用）。

### 阵营配置

|---|---|---|---|---|---|---|---|
| 水手 | 3或2 | 3 | 4 | 4 | 5 | 5 | 5 |
| 海盗 | 1或2 | 2 | 2 | 3 | 3 | 4 | 4 |
| 邪教主 | 1 | 1 | 1 | 1 | 1 | 1 | 1 |
| 邪教徒 | - | - | - | - | - | - | 1 |

- 5人局：3水手/1海盗 或 2水手/2海盗（从5个袋子中随机移除1个，概率 3/5 与 2/5）。
- 海盗开局互相认识（秘密集结）；11人局邪教主与邪教徒互不相识。
- 角色牌 22 张：洗混 21 张非船长牌 → 抽出（人数-1）张 → 加入船长牌 → 洗混发每人1张 → 船长牌持有者立即亮出，为第一任船长，弃船长牌并从剩余牌中随机抽1张新角色牌。

## 4. 胜利条件
1. 船抵达东侧蓝湾（Bluewater Bay）→ 水手全队胜。
2. 船抵达西侧绯红湾（Crimson Cove）→ 海盗全队胜。
3. 船抵达北方海妖（Cult Victory）→ 邪教全队胜。
4. 邪教主在"献祭海妖"格被献祭 → 邪教全队胜（含邪教徒）。
- 邪教主以 navigator 身份跳海不能获胜（即使在海妖格）。
- 队员即使中途出局（跳海/献祭）仍随队伍获胜。

## 5. 回合流程（状态机）
```
R1 任命航海组 (activation window: 任命前)
R2 忠诚质询（秘密出枪 → 同时揭示 → 揭示后 window → 结算）
R2.1 哗变成功 → 弃揭示的枪 → 定新船长（平局链）→ 本轮结束，新船长开新一轮
R2.2 哗变失败 → 枪归位 → 进入航海
R3 航海：抽牌前 window → 船长抽2 → 副手抽2 → 各弃1入深海 → 航海日志洗混 → 领航员看2弃1（可拒令跳海）→ 船长亮牌
R3.1 执行：I 移动船只 → 检查胜利 → 补给线 → II 地图行动 → III 导航牌行动
R3.2 黄牌时 Spiritualist window；邪教暴动牌 → 航海结束前揭示仪式牌并执行
R4 停职：按人数发停职牌（5-6:船长；7-8:船长+副手；9-11:船长+副手+领航员），原停职解除
下一轮：现任船长继续任船长，重新任命
```
- 洗牌：抽牌堆 <4 张时（航海前）与弃牌堆合洗。简历牌不回洗。
- 少于3人存活：空缺职位由船长随机解决（抽2随机弃1模拟副手/领航员决策）。

### 哗变
| 人数 | 成功所需枪数 |
|---|---|
| 5-7 | ≥3 |
| 8-9 | ≥4 |
| 10-11 | ≥5 |
- 除船长外每人秘密提交 0..n 把枪，同时揭示。
- 成功：揭示最多枪者为新船长（割舌者按0枪计）；平局→现任船长指定1名平局者退出→被指定者继续指定→剩1人为新船长。
- 所有参与成功哗变者弃掉揭示的枪（含新船长）。
- 停职者可参与哗变、可成为船长。

### 停职规则
- 停职者不能被任命为副手/领航员；可哗变、可为船长；船长停职则停职对其无效（任船长期间）。
- 可任命人数不足时忽略停职。
- 停职牌仅在成功航海后移交，哗变后不移交。

### 拒令跳海（Emergency Navigation）
- 领航员看到两张牌后可拒令：两牌面朝下弃掉，领航员立即出局禁言。
- 船长立即指定紧急领航员（可为停职者）；无忠诚质询；副手不变；立即重新航海。
- 紧急领航员也可跳海，循环直到完成一次航海。
- 邪教主跳海不能获胜。

### 补给线（仅长航程）
- 船越过补给线时，所有玩家补枪至3（已有≥3支不补）。

## 6. 地图行动（进格即触发，先于导航牌行动；船长决策）
- **舱室搜查**：船长选1人，秘密查看其阵营。被搜查者此后不可被皈依。若其已是邪教徒，船长也会得知（触手手势规则）。
- **鞭刑**（7-11人长图）：船长选1人；被罚者秘密按当前阵营选牌（水手蓝/海盗红/邪教黄绿）；船长从其余2张中随机揭示1张 → 公开"我不是X"。被罚者不可再被皈依。
- **割舌**：船长选1人；其不能再当船长；定新船长时按0枪计（哗变总数照常计）。
- **献祭海妖**：船长选1人（不能选自己）立即出局禁言。若被选者是邪教主→邪教全队立即胜利。

## 7. 导航牌行动
- **Drunk 醉酒**：现任船长卸任；船长职移交给顺时针方向下一个（简历牌最少者）；割舌者忽略。新船长继续本轮（未任命时任命新组；已进入航海则已无影响——注：醉酒牌是导航结果牌，此时本轮航海已完成，新船长从下轮任命开始）。
- **Mermaid 美人鱼**：船长选1人，其秘密查看最近3张弃牌，可撒谎。
- **Telescope 望远镜**：船长选1人，其看抽牌堆顶1张，可面朝下弃掉或放回。
- **Armed 武装**（仅长图）：领航员从供应区+1枪。
- **Disarmed 缴械**：领航员弃1枪（若有）。
- **Cult Uprising 邪教暴动**：本轮航海结束时船长揭示1张背面朝上的邪教仪式牌（即洗混顺序的下一张）：
  - **皈依邪教**（×3）：邪教主秘密选1名可皈依者（未被舱搜/鞭刑者）变邪教徒，弃原阵营。
  - **邪教军火库**（×1）：邪教主秘密将3把供应区枪分配给任意玩家（可含自己、可集中）。
  - **邪教舱搜**（×1）：邪教主秘密得知当前航海组三人阵营。

## 9. 关键裁决记录（规则书未明说处的实现决定）
1. Drunk 平局：简历最少者为多人时，从船长顺时针扫描的第一个（排除现任船长与割舌者）。
2. Spiritualist 时机：在本轮导航牌行动完成后、仪式前开启窗口。
3. "任意时机"角色的数字化裁定：可在任意响应窗口激活（提交枪阶段除外）。
4. 哗变失败也开启"枪揭示后"窗口（揭示总是发生）。
5. Telescoping 后放回的牌不洗。
6. 献祭后若导航组被献祭（副手/领航员），航海继续完成（其决策已完成）。
7. Minstrel/Agitator/Equalizer 等效果持续到"下次哗变"结算完毕后清空。
8. Gunsmith 收回的是本次哗变中自己使用的枪中的1把。
9. 补给线：每次从南侧越线进入线北格时触发（通常仅一次）。
10. 角色牌与阵营无关；11人局第一邪教徒与邪教主互不相识（各自私密提示）。

## 11. 补充裁决（fuzz 测试中发现规则书未覆盖的情形）
